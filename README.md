# Finance Club Simulator

**A stock market simulation and financial learning platform for students and finance clubs.**

Finance Club Simulator is a web-based project designed to make practical investment education more accessible. The goal is to give students a space to explore portfolio management, understand market movements, and eventually participate in simulated investment competitions without risking real money.

## Project Overview

Financial concepts are often taught theoretically, with limited opportunities for students to apply them in realistic investment scenarios.

Finance Club Simulator aims to bridge this gap by providing an accessible platform for portfolio analysis, simulated trading, and competitive financial learning.

The project is currently in active development, with an initial dashboard prototype built using simulated financial data.

## Current Features

The initial frontend implementation includes:

- **Portfolio Dashboard:** Visual representation of portfolio value, performance, and financial metrics.
- **Holdings Analysis:** Interface for reviewing investment holdings and portfolio composition.
- **Performance Visualisation:** Charts and indicators for understanding investment performance.
- **Trading History:** Dashboard views for reviewing simulated transaction records.
- **Market Overview:** Financial indicators and market information presented through an interactive interface.
- **Competition Tracking:** Interface elements designed around investment competitions and participant performance.

These are prototype interface features, not a complete production trading system.

## Technology Stack

- **Framework:** Next.js
- **Frontend:** React and TypeScript
- **Styling:** Tailwind CSS
- **Data Visualisation:** Recharts
- **Icons:** Lucide React

## Getting Started

To run the project locally:

**1. Clone the repository**

`git clone https://github.com/harshjain5634-code/finance-club-simulator.git`

**2. Enter the project directory**

`cd finance-club-simulator`

**3. Install dependencies**

`npm install`

**4. Start the development server**

`npm run dev`

**5. Open the application**

Visit `http://localhost:3000` in your browser.
